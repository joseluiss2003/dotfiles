# SwayP theme wallpaper pools

Each theme can ship its own wallpaper pool. Current curated pools:

- `catppuccin/`
- `gruvbox/`
- `kanagawa/`
- `osaka-jade/`
- `miasma/`
- `rose-pine/`
- `ristretto/`
- `last-horizon/`

The current pool provides one curated default per theme. The wallpapers are intentionally kept dark and palette-aligned so the TUI shell remains readable.

When a pool is present, its `01.*` image is used as the default wallpaper and selector preview.
