# SwayP Quickshell

Quickshell is the UI layer of SwayP. It hosts the bar, panels, popups, widgets and shared desktop services in a single shell process.

## Current structure

- `shell.qml` — shell entry point and orchestration.
- `Commons/` — shared/core QML components. This directory is being renamed to `core/`.
- `Ui/` — reusable UI components. This directory is being renamed to `ui/`.
- `services/` — shared application services and registries.
- `plugins/` — bar widgets, panels and service plugins.
- `generated/` — files generated by Matugen.

## Migration

This configuration originally contained Omarchy-specific compatibility layers. SwayP is progressively removing those assumptions and giving the shell its own naming, paths and contracts.

The migration is deliberately incremental: structure is changed first, then internal imports and runtime identifiers are updated, and only afterwards are obsolete compatibility pieces removed.
